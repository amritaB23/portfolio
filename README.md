# Amrita Bera · Portfolio

My personal portfolio website: about me, skills, projects and experience.

Built with plain **HTML, CSS and JavaScript** (no framework):

- CSS variables for colours, with automatic dark mode (`prefers-color-scheme`)
- Responsive layout with CSS Grid and Flexbox, plus a mobile hamburger menu
- Accessible markup: semantic sections, `aria-expanded` on the menu button

Featured project: [SplitEasy](https://github.com/amritaB23/spliteasy), an app for splitting expenses with friends.

## Run locally

Open `index.html` in a browser, or run `npx serve .`
